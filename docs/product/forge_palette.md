# The Forge Palette - AI Agent Factory Brand Theme

| Role | Color Name | Hex Code | Visual / Psychological Purpose |
| :--- | :--- | :--- | :--- |
| **Primary (60%)** | **Carbon Steel** | `#1E2022` | Industrial matte charcoal that mimics heavy machinery and physical foundry frames. |
| **Secondary (30%)** | **Industrial Ochre** | `#EAA115` | A warnings-and-construction style yellow-orange signaling manual labor, assembly lines, and heavy-duty utility. |
| **Accent (10%)** | **Anvil Gray** | `#667085` | A cold, metallic structural color used for disabled buttons, secondary lines, and tags. |
| **Neutral Background** | **Off-White Offsetting** | `#F4F5F6` | Minimizes eye strain while maintaining a distinct stark, hardware-inspired canvas. |
