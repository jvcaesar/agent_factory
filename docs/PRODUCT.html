From a five-minute conversation to a governed, durable team of AI agents.

Agent Factory is a CLI that turns intent — an interview, a YAML file, or a pre-built pack — into a complete org chart of specialized agents with roles, SOPs, goals, shared memory, and a human-in-the-loop channel. Durable state, risk-tiered guardrails, and your choice of LLM are built in.

What it does

Describe the company. Get the workforce.

Five verbs cover the whole product — and every one of them records its work in a database you own.

1

🏭 Bootstrap — intent in, org chart out

An interactive interview, a YAML spec, or a pre-built pack generates a validated org chart: 20+ roles with titles, reporting lines, SOPs, tool grants, and goals.

agent_factory bootstrap --pack business_ops --name "Demo Co" --out orgs/Demo
2

⚙️ Run — every role is a real agent

Each role runs the agent loop (LLM actions → granted tools → approval gating) against a durable SQLite store. Every job, result, and event is recorded.

agent_factory run --org orgs/Demo --role worker_research_1 --task "…"
3

🚀 Grow — the lead takes initiative, safely

A proactive lead proposes its own next steps against the north star — risk-rated and prioritized — and executes them only within your guardrails.

agent_factory ambition --org orgs/Demo --role lead_exec --max-actions 2
4

👀 Observe — mission control & morning brief

A watchdog observer surfaces friction and blockers as insights; the lead briefs you: what should I do today?

agent_factory status --org orgs/Demo  ·  brief --org orgs/Demo
5

💬 Talk — humans in the loop, in-channel

Post a question to #general; the addressed role answers in-thread using its normal tools and permissions. Atomic claims mean never a double reply.

agent_factory channel post --org orgs/Demo --text "Did the client respond?"

Portable orgs

An org is files plus one SQLite file. Copy it, commit it, reset it by deleting jobs.db.

Governance & safety

Initiative without chaos

Every safeguard below is enforced in code and recorded as data — not promised in a system prompt.

Least privilege

Roles only get the tools their YAML grants them.

Risk tiers

Every tool carries low / medium / high risk; org policy decides which tiers need approval.

Approval policies

deny (safe default) / ask / allow — overridable per run, every decision recorded as an event.

Bounded initiative

Proactive actions have a --max-risk ceiling and --max-actions budget; over-ceiling proposals are logged, never executed.

Exactly-once answers

Channel claims are atomic in SQLite — two workers or a crash can never double-reply.

Fully auditable

Jobs, events, approvals, insights, messages — rows in a database you own.

Developer experience

Zero to workforce in five commands

No keys, no cost, no network. Deterministic offline output for tests, CI, and demos — switch to real intelligence by changing one variable.

get started — fully offline 
pip install -e .              # Python 3.10+, no API key needed
set AGENT_FACTORY_PROVIDER=fake   # offline & deterministic

agent_factory bootstrap --pack business_ops --name "Demo Co" --out orgs/Demo
agent_factory run --org orgs/Demo --role worker_research_1 --task "List the quarterly targets."
agent_factory status --org orgs/Demo
